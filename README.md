# CogniStream: Developer Flow-State & Cognitive Load Analytics

## 📌 Overview

CogniStream is an analytics platform designed to understand developer
flow state, cognitive load, productivity patterns, and development
behavior using data-driven insights.

The project collects and analyzes developer activity data to identify
patterns related to productivity, interruptions, workload, and cognitive
load.

## 🎯 Objectives

- Measure developer productivity and flow-state patterns.
- Analyze cognitive load during development activities.
- Identify factors that cause interruptions and context switching.
- Generate meaningful analytics from developer activity data.
- Provide interactive dashboards for understanding development behavior.
- Support data-driven decisions for improving developer experience.
